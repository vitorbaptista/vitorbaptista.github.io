# Áudios locais

Coloque aqui gravações MP3 opcionais para os itens do teste.

O nome do arquivo precisa ser o identificador do item, por exemplo:

- `palavras-curtas-p-pato.mp3`
- `palavras-curtas-g-gola.mp3`
- `frases-curtas-ch-chave-nova.mp3`

Quando o app estiver em `Arquivos MP3 locais`, ele tenta tocar esse arquivo. Se o
arquivo não existir, ele usa a voz pt-BR do navegador.
